KryptonMCP

Zero-Trust AI Security & Privacy Gateway

KryptonMCP is a high-performance pure Go security gateway for Model Context Protocol (MCP) tool pipelines, providing in-flight PII masking (~33μs), prompt injection guardrails, ephemeral database credentials, and cryptographic RFC 6962 Merkle audit logging.

  • Pure Go
  • Model Context Protocol
  • RFC 6962 Merkle
  • ~33μs In-Flight PII Masking
  • Prompt Injection Guardrails
  • JIT Ephemeral DB Credentials
  • Signed Merkle Audit Ledger
